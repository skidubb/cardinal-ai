# CMO Skill: Content Strategy for Professional Services

## When to Use
Invoke this skill when developing thought leadership programs, content marketing strategies, or planning content calendars for a consulting/agency business.

## Content Strategy Framework

### 1. Content Strategy Pyramid

```
                    ▲
                   /│\
                  / │ \
                 /  │  \      SIGNATURE CONTENT
                /   │   \     (Annual research, books)
               /────┼────\
              /     │     \   HERO CONTENT
             /      │      \  (Major reports, keynotes)
            /───────┼───────\
           /        │        \ THOUGHT LEADERSHIP
          /         │         \(POV articles, case studies)
         /──────────┼──────────\
        /           │           \ ENGAGEMENT CONTENT
       /            │            \(Social posts, newsletters)
      /─────────────┼─────────────\
     /              │              \ FOUNDATION CONTENT
    /               │               \(Service pages, FAQs, team bios)
   ──────────────────────────────────
```

### 2. Content Strategy Matrix

| Content Type | Funnel Stage | Primary Goal | Frequency | Resources |
|--------------|--------------|--------------|-----------|-----------|
| POV Articles | Awareness | Establish expertise | 2-4/month | Writer + SME |
| Case Studies | Consideration | Prove results | 1-2/quarter | Writer + Client |
| Research Reports | Awareness | Build authority | 1-2/year | Major investment |
| Webinars | Interest | Engage audience | 1/month | Speaker + Production |
| Newsletters | Nurture | Stay top of mind | 1-2/week | Curator + Writer |
| Social Content | All | Drive engagement | Daily | Social manager |

### 3. Thought Leadership Development Process

```markdown
## Thought Leadership Playbook

### Phase 1: Research & Insight Development
- [ ] Conduct original research (surveys, interviews, data analysis)
- [ ] Identify contrarian/valuable point of view
- [ ] Validate with clients/prospects
- [ ] Document supporting evidence

### Phase 2: Hero Asset Creation
- [ ] Develop comprehensive whitepaper or report
- [ ] Executive summary version
- [ ] Visual assets (charts, infographics)
- [ ] Presentation deck version

### Phase 3: Atomization
Break the hero asset into:
- [ ] 3-5 derivative articles
- [ ] 10-20 social media posts
- [ ] Speaking abstract/one-pager
- [ ] Email series
- [ ] Podcast talking points

### Phase 4: Activation
- [ ] Media outreach plan
- [ ] Paid amplification budget
- [ ] Email campaign
- [ ] Sales enablement briefing
- [ ] Speaking pitch to conferences

### Phase 5: Measurement
- [ ] Content engagement metrics
- [ ] Lead generation attribution
- [ ] Media coverage tracking
- [ ] Speaking invitation volume
```
