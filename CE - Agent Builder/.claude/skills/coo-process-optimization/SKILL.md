# COO Skill: Process Optimization for Professional Services

## When to Use
Invoke this skill when analyzing processes, identifying efficiency improvements, or implementing operational changes.

## Process Optimization Framework

### 1. Process Assessment Model

```markdown
## Process Health Checklist

### Effectiveness (Does it achieve the goal?)
- [ ] Clear desired outcome defined
- [ ] Output meets quality standards
- [ ] Stakeholders satisfied with results
- [ ] Aligned with business objectives

### Efficiency (Does it use resources well?)
- [ ] Appropriate time investment
- [ ] Right people involved (not too many/few)
- [ ] Minimal rework and waste
- [ ] Automation where appropriate

### Compliance (Does it meet requirements?)
- [ ] Follows required policies
- [ ] Meets regulatory requirements
- [ ] Documented appropriately
- [ ] Auditable when needed

### Adaptability (Can it handle change?)
- [ ] Handles exceptions gracefully
- [ ] Scalable for growth
- [ ] Easy to modify when needed
- [ ] Not dependent on specific individuals
```

### 3. Improvement Analysis

```markdown
## Improvement Opportunity Analysis

### Categories of Waste (TIMWOODS)
| Waste Type | Example in Process | Impact | Solution |
|------------|-------------------|--------|----------|
| **T**ransportation | Moving work between systems | Delays | Integrate systems |
| **I**nventory | Work waiting in queues | Cash/time | Reduce batch sizes |
| **M**otion | Searching for information | Time | Better organization |
| **W**aiting | Approvals, dependencies | Delays | Parallel processing |
| **O**verproduction | Creating unused reports | Waste | Eliminate |
| **O**verprocessing | Excessive review cycles | Time | Streamline |
| **D**efects | Errors requiring rework | Quality/time | Error-proofing |
| **S**kills | Underutilized talent | Potential | Better matching |

### Root Cause Analysis (5 Whys)
Problem: [State the problem]
1. Why? [First cause]
2. Why? [Second cause]
3. Why? [Third cause]
4. Why? [Fourth cause]
5. Why? [Root cause]

Root Cause: [Underlying issue to address]
```

### 4. Solution Evaluation Matrix

| Solution | Impact | Effort | Risk | Score | Priority |
|----------|--------|--------|------|-------|----------|
| [Solution 1] | H/M/L | H/M/L | H/M/L | [1-9] | [Rank] |
| [Solution 2] | H/M/L | H/M/L | H/M/L | [1-9] | [Rank] |

**Scoring**: Impact (H=3, M=2, L=1) × (4-Effort) × (4-Risk)

### 5. Implementation Plan

```markdown
## Change Implementation

### Phase 1: Prepare
- [ ] Document current state
- [ ] Communicate change to stakeholders
- [ ] Train team on new process
- [ ] Set up tools/systems

### Phase 2: Pilot
- [ ] Run pilot with subset
- [ ] Gather feedback
- [ ] Refine based on learnings
- [ ] Document issues and solutions

### Phase 3: Rollout
- [ ] Full implementation
- [ ] Monitor closely
- [ ] Address issues quickly
- [ ] Celebrate wins

### Phase 4: Sustain
- [ ] Establish ongoing metrics
- [ ] Regular process reviews
- [ ] Continuous improvement
- [ ] Document and train
```
