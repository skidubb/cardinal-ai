CE – Agent Builder

src/csuite/

The agent factory. Builds fully-equipped AI executives with tools, memory, and learning. Two backends: legacy (raw Anthropic API with tool loop) and SDK (Claude Agent SDK with MCP servers). Both expose the same async chat(message) → str interface.

Core Agent Classes

  • BaseAgent — Abstract base. Session management, system prompt builder, tool execution loop (max 15 iterations), cost ceiling enforcement
  • SdkAgent — Claude Agent SDK adapter. Per-role MCP servers, post-response self-evaluation, experience logging
  • factory.py — Routes to SDK or legacy based on AGENT_BACKEND config setting

  • COO — Ops, scaling, resource allocation (temp: 0.6)
  • CPO — Product-market fit, roadmap (temp: 0.6)
  • CRO — Revenue, pipeline, GTM (temp: 0.6)

CE – Multi-Agent Orchestration

protocols/

50 coordination protocols that orchestrate agents through structured reasoning patterns. Each protocol is a standalone Python module with an orchestrator class, prompt templates, and a CLI entry point. Blackboard-driven state machine dispatches stages when triggers match.

Core Architecture

Engine Orchestrator Loop

  • Blackboard — Append-only shared state store. Topics, versioning, role-scoped reads, watcher callbacks
  • Stage Executors — Factory functions: parallel_agent_stage(), sequential_agent_stage(), mechanical_stage(), synthesis_stage()
  • Orchestrator — Pure state machine: while pending stages, check triggers, dispatch. Never reads content—only checks triggers and fires stages
  • LLM Dispatch — Routes calls: AgentBridge.chat() for production, LiteLLM for multi-provider, raw Anthropic for research mode

Tiers Dual Model Strategy

  • Thinking Model (Opus) — Agent reasoning, synthesis, creative stages. Extended thinking with 10K token budget
  • Orchestration Model (Haiku) — Dedup, ranking, extraction, classification. Fast mechanical steps
  • Balanced Model (Sonnet) — Middle tier for structured analysis
  • LiteLLM — Multi-provider support for Gemini, GPT, Grok. Per-agent model override via agent["model"]

Bridge Agent Provider

  • Production mode (default) — build_production_agents() creates real SdkAgent instances wrapped in AgentBridge
  • Research mode — Lightweight dicts from agents.py registry. Opt-in via --mode research or AGENT_MODE=research
  • AgentBridge — Dict-compatible wrapper. Supports both agent["name"] access and agent.chat(msg)
  • Path resolution — Finds Agent Builder via CE_AGENT_BUILDER_PATH env or sibling directory

API FastAPI + React

  • Server — FastAPI with lifespan hooks, CORS, optional API key auth
  • Runner — SSE streaming protocol execution. Dynamic orchestrator discovery via glob + regex
  • Routers — /api/protocols, /api/runs, /api/agents, /api/teams, /api/pipelines, /api/knowledge, /api/reports
  • UI — React/TypeScript + Vite. Dashboard, protocol library, run history, agent registry, settings

Observe Observability

  • Langfuse — @trace_protocol decorator on every orchestrator. Root span + child spans for stages. Generation tracking for LLM calls
  • Postgres — persist_run() writes run metadata, result JSON, cost, trace_id to runs table
  • Cost Tracker — ProtocolCostTracker aggregates per-model, per-agent token usage via ce_shared.pricing
  • Both degrade gracefully when not configured

Pattern Protocol Module Structure

  • __init__.py — Exports orchestrator class + result dataclass
  • orchestrator.py — Async class with run(question) → *Result
  • prompts.py — All LLM prompt templates as string constants
  • run.py — CLI entry point with argparse

All accept: -q, -a, --thinking-model, --orchestration-model, --mode

CE – Evals

src/ce_evals/core/

Library-only evaluation framework. Anonymizes protocol outputs, sends them to multi-model judge panels, and aggregates blind scores against YAML rubrics. Detects disagreements, computes regressions vs. baseline.

Core BlindJudge

  • Takes {name: response} dict, anonymizes as Response A/B/C
  • Sends to 3 judge models concurrently (Claude Opus, GPT-5.2, Gemini Pro)
  • Aggregates via mean + std dev, Borda count ranking
  • Flags disagreements when std dev > 1.0
  • Returns (aggregated_result, per_judge_results)

Backends Multi-Provider

  • AnthropicBackend — Claude models via Anthropic SDK
  • OpenAIBackend — GPT-4o, o1, o3 with reasoning effort config
  • GeminiBackend — Google Gemini with ThinkingConfig for extended thinking
  • All implement: call(system, user, model, temp) → (text, in_tok, out_tok)

Config Rubrics & Runner

  • Rubrics — YAML with dimensions (name, description, 1-5 scale). Generates judge system prompts with {{dimensions}} injection
  • Runner — EvalRunner orchestrates: run protocols, collect outputs, judge, persist to ce-db
  • Cost — Token pricing lookup for all models. Feb 2026 rates with caching multipliers
  • Regressions — quality_delta, variance_delta, cost_per_correct_delta vs. baseline

Execution Sequence

A protocol run from API request through agent execution to persisted result. This traces the P04 Multi-Round Debate path; other protocols follow the same envelope with different internal stages.

1

Client Request

POST /api/protocols/run with protocol_key, question, agent_keys, rounds. React UI or direct API call. Returns SSE stream.

2

Create Run Record

FastAPI router creates a Run row in Postgres (status: pending). Initializes ProtocolCostTracker and Langfuse root trace via @trace_protocol.

3

Build Production Agents

build_production_agents(["ceo", "cfo", "cto"]) resolves Agent Builder's SdkAgent for each key. Wraps in AgentBridge for dict + chat() access. Falls back to research dicts if Agent Builder unavailable.

4

Load Orchestrator

_discover_orchestrators() globs protocols/p*/orchestrator.py, regex-matches class names. Dynamic import of DebateOrchestrator. Instantiate with agents, models, rounds.

5

Execute Rounds

For each round: asyncio.gather() queries all agents in parallel. Each call routes through agent_complete() → AgentBridge.chat() → SdkAgent (tools, memory, learning). SSE events stream per-agent responses to client.

6

Synthesis

SynthesisEngine aggregates all arguments. Calls Opus with extended thinking (10K token budget). Produces unified strategic recommendation. SSE: synthesis_complete.

7

Persist & Score

persist_run() writes Run metadata, AgentOutput rows, cost summary to Postgres. Links Langfuse trace_id. Optional QualityJudge scores the synthesis.

8

Evaluate (Optional)

CE-Evals BlindJudge anonymizes protocol outputs. Three models (Claude, GPT, Gemini) score against YAML rubric. Aggregates Borda ranking. Persists to eval_samples + eval_regressions.

Infrastructure

Docker Compose orchestrates Postgres, Metabase, and the FastAPI backend. Multi-stage Dockerfile builds React UI then Python runtime. CI runs lint, type-check, and tests for all three projects.

Docker Compose Services

  • postgres:16 — ce_platform DB with pgdata volume. Healthcheck on startup
  • metabase — BI dashboard on port 3001. Connects to postgres
  • backend — FastAPI (port 8000). Multi-stage build: Node 22 for UI, Python 3.11 for runtime
  • Langfuse Cloud — External SaaS. Env vars: LANGFUSE_SECRET_KEY, LANGFUSE_PUBLIC_KEY

Build Multi-Stage Dockerfile

  • Stage 1 — Node 22: npm ci + vite build for React UI → /dist
  • Stage 2 — Python 3.11 slim: installs ce-shared, ce-db, Agent Builder ([sdk]), Orchestration deps
  • Copies UI dist into FastAPI static dir
  • Sets CE_AGENT_BUILDER_PATH, strips .env files
  • Runs: uvicorn api.server:app --host 0.0.0.0 --port 8000

CI/CD GitHub Actions

  • Agent Builder — ruff check + mypy + pytest -m "not integration"
  • Orchestration — ruff check + pytest + vite build
  • Evals — pytest full suite
  • Triggers: push to main, PRs to main
  • Python 3.13, Node 20

Data Database Schema

  • runs — protocol_key, question, status, result_json, cost, trace_id, judge verdict
  • agent_outputs — run_id FK, agent_key, output_text, tool_calls, cost, tokens
  • run_steps — Pipeline checkpoints for resume
  • eval_runs — Eval batch metadata
  • eval_samples — Per-candidate scores, variance, cost
  • eval_regressions — Delta tracking vs. baseline
